# Scratch Guard

Marketing website for **Scratch Guard — Protect Door Weather Stripping**.

## Files
- `index.html` — complete self-contained marketing site
- `thank-you.html` — form submission confirmation page

The HTML files are self-contained so the logo, before/after product photos, and infographic are embedded directly in the pages. This makes GitHub updates and static hosting simple.

## Hosting with Netlify
1. Connect this GitHub repository to Netlify.
2. Use the repository root as the publish directory.
3. No build command is required.
4. Enable Netlify form detection.
5. Deploy.

The site currently includes:
- Responsive mobile/desktop design
- Before/after product photos
- Research-backed energy-efficiency context
- Scratch Guard infographic
- Launch pricing framework
- Early-access / preorder interest form
- Contact / quote-request form
- Netlify-compatible form attributes

## Forms
Netlify form names:
- `scratch-guard-preorder`
- `scratch-guard-contact`

## Updating
Edit `index.html` or ask ChatGPT to update this repository. Once Netlify is connected to the `main` branch, pushes to `main` can redeploy automatically.

## Pricing
Pricing on the site is a launch framework and should be confirmed against final manufacturing, packaging, shipping, and fulfillment costs before paid ecommerce is enabled.
